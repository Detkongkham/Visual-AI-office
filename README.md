# ຫ້ອງການ AI Dev

ຫ້ອງການ 2D ທີ່ພະນັກງານ AI ທັງ 15 ຄົນ**ເຮັດວຽກແທ້**ດ້ວຍ [Claude Agent SDK](https://code.claude.com/docs/en/agent-sdk). ເຈົ້າສັ່ງວຽກ ແລ້ວເບິ່ງພວກເຂົາຍ່າງໄປໂຕະ, ອ່ານ ແລະ ແກ້ໄຂໄຟລ໌ ແລະ ຂໍອະນຸຍາດກ່ອນລັນຄຳສັ່ງ.

## ຕິດຕັ້ງ ແລະ ເປີດໃຊ້

ຕ້ອງມີ Node.js 18 ຂຶ້ນໄປ.

```bash
cd ~/vao/ai-office
npm install
cp .env.example .env
```

ເປີດໄຟລ໌ `.env` ແລ້ວໃສ່ API key ຂອງເຈົ້າ (ສ້າງໄດ້ທີ່ https://console.anthropic.com):

```
ANTHROPIC_API_KEY=sk-ant-...
```

ຈາກນັ້ນເປີດ server:

```bash
npm start
```

ເປີດ browser ໄປທີ່ **http://localhost:4317**

| ສິ່ງທີ່ຢາກເຮັດ | ວິທີ |

| ສັ່ງວຽກ | ພິມວຽກໃນກ່ອງລຸ່ມສຸດ, ເລືອກຄົນ (ຫຼື "ໃຫ້ AI ເລືອກຄົນ") ແລ້ວກົດ **ສົ່ງວຽກ** |
| ເບິ່ງວ່າເຮັດຫຍັງຢູ່ | ຄົນທີ່ກຳລັງເຮັດວຽກຈະຍ່າງກັບໄປນັ່ງໂຕະ ແລະ ມີຟອງບອກວ່າກຳລັງເຮັດຫຍັງ ເຊັ່ນ "ອ່ານ app.js" ຫຼື "ແກ້ໄຂ index.html" |
| ອະນຸຍາດຄຳສັ່ງ | ເມື່ອມີຄົນຂໍລັນຄຳສັ່ງ ຈະມີກ່ອງສີສົ້ມ **ຂໍອະນຸຍາດ** ຢູ່ແຜງຂວາ. ອ່ານຄຳສັ່ງໃຫ້ດີ ແລ້ວກົດ ອະນຸຍາດ ຫຼື ບໍ່ອະນຸຍາດ |
| ເບິ່ງຜົນລັບ | ກົດໃສ່ວຽກໃນລາຍການ **ວຽກ** ເພື່ອເບິ່ງສະຫຼຸບ, ບັນທຶກການເຮັດວຽກ ແລະ ຄ່າໃຊ້ຈ່າຍ |
| ຢຸດວຽກ | ເປີດວຽກນັ້ນ ແລ້ວກົດ **ຢຸດວຽກນີ້** |
| ປ່ຽນໂມເດວ | ກົດໃສ່ພະນັກງານ ແລ້ວເລືອກ **ໂມເດວ** (Haiku / Sonnet / Opus / Fable) ແລະ **ລະດັບການຄິດ** ໃນບັດ. ບັນທຶກລົງ `config/team.json` ທັນທີ |

## ສິດຂອງແຕ່ລະຄົນ

- **ອ່ານໄດ້ຢ່າງດຽວ** (CEO, Code Reviewer, Security Engineer, Scrum Master): ອ່ານ ແລະ ຄົ້ນຫາໄຟລ໌ເທົ່ານັ້ນ ບໍ່ສາມາດແກ້ໄຂໄດ້
- **ອ່ານ ແລະ ແກ້ໄຂໄດ້** (ຄົນອື່ນໆ): ອ່ານ ແລະ ແກ້ໄຂໄຟລ໌ໃນ workspace ໄດ້ເອງ. **ການລັນຄຳສັ່ງທຸກຢ່າງ ແລະ ການເຂົ້າເຖິງນອກ workspace ຕ້ອງຂໍອະນຸຍາດຈາກເຈົ້າກ່ອນ**

ທຸກຄົນຖືກສັ່ງວ່າຫ້າມ push, deploy ຫຼື publish.

## ການຕັ້ງຄ່າ (`.env`)

| ຕົວແປ | ຄວາມໝາຍ | ຄ່າເລີ່ມຕົ້ນ |
|---|---|---|
| `ANTHROPIC_API_KEY` | API key ຂອງເຈົ້າ | (ຕ້ອງໃສ່) |
| `PORT` | port ຂອງໜ້າເວັບ | 4317 |
| `WORKSPACE_DIR` | ໂຟນເດີທີ່ທີມເຮັດວຽກ. ປ່ຽນເປັນ path ຂອງໂປຣເຈັກແທ້ໄດ້ | `./workspace` |
| `TASK_BUDGET_USD` | ເພດານຄ່າໃຊ້ຈ່າຍຕໍ່ວຽກ | 1.00 |
| `DAILY_BUDGET_USD` | ເພດານຄ່າໃຊ້ຈ່າຍຕໍ່ມື້. ເກີນແລ້ວຈະບໍ່ຮັບວຽກໃໝ່ | 10.00 |

ບົດບາດ, prompt, ໂມເດວ ແລະ ສິດຂອງແຕ່ລະຄົນ ແກ້ໄດ້ໃນ `config/team.json`.

## ໂຄງສ້າງໂປຣເຈັກ

```
ai-office/
├── server/
│   ├── index.js    # web server, ຄິວວຽກ, ຄຳຂໍອະນຸຍາດ, ອັບເດດສົດ (SSE)
│   ├── runner.js   # ລັນວຽກດ້ວຍ Claude Agent SDK ແລະ ແປງການໃຊ້ tool ເປັນກິດຈະກຳ
│   └── store.js    # ບັນທຶກວຽກ ແລະ ຄ່າໃຊ້ຈ່າຍລົງ data/state.json
├── web/            # ໜ້າຫ້ອງການ 2D (ຮູບຈາກ vao/model, vao/room, vao/item)
├── config/team.json
└── workspace/      # ໂຟນເດີທີ່ AI ເຮັດວຽກ
```

## ຂໍ້ຄວນຮູ້

- ພະນັກງານຫຼາຍຄົນເຮັດວຽກ**ພ້ອມກັນ**ໄດ້ ແຕ່ຄົນດຽວຮັບໄດ້ເທື່ອລະວຽກ (ວຽກອື່ນຈະເຂົ້າຄິວ). ທຸກຄົນໃຊ້ workspace ດຽວກັນ ຖ້າສັ່ງໃຫ້ 2 ຄົນແກ້ໄຟລ໌ດຽວກັນພ້ອມກັນ ອາດຂຽນທັບກັນ
- ຄ່າໃຊ້ຈ່າຍທີ່ສະແດງເປັນການຄາດຄະເນຈາກ SDK. ວຽກທີ່ຖືກຢຸດກາງຄັນຈະບໍ່ຖືກນັບຄ່າໃຊ້ຈ່າຍ
- server ເປີດສະເພາະໃນເຄື່ອງນີ້ (`127.0.0.1`) ເຄື່ອງອື່ນເຂົ້າບໍ່ໄດ້
