# ຫ້ອງການ AI Dev

ຫ້ອງການ 2D ທີ່ພະນັກງານ AI ທັງ 15 ຄົນ**ເຮັດວຽກແທ້**ດ້ວຍ [Claude Agent SDK](https://code.claude.com/docs/en/agent-sdk). ເຈົ້າສັ່ງວຽກ ແລ້ວເບິ່ງພວກເຂົາປະຊຸມວາງແຜນ, ຍ່າງກັບໂຕະ, ອ່ານ ແລະ ແກ້ໄຂໄຟລ໌ ແລະ ຂໍອະນຸຍາດກ່ອນລັນຄຳສັ່ງ.

## ເປີດໃຊ້

ຕ້ອງມີ Node.js 18 ຂຶ້ນໄປ ແລະ **login Claude Code ໄວ້ໃນເຄື່ອງນີ້** (ເຊັ່ນ ຜ່ານ extension Claude Code ໃນ Antigravity: ພິມ `/login`).

```bash
cd ~/vao/ai-office
npm install
npm start
```

ເປີດ **http://localhost:4317**. ປ້າຍມຸມຊ້າຍເທິງຈະບອກວ່າເຊື່ອມຕໍ່ແລ້ວບໍ:

| ປ້າຍ | ຄວາມໝາຍ |
|---|---|
| 🟢 ເຊື່ອມກັບ Claude Code ແລ້ວ · Claude Pro | ໃຊ້ login Claude Code ຂອງເຈົ້າ (ແບ່ງກັບ Antigravity / CLI) |
| 🟢 ໃຊ້ API key ຈາກ .env | ບໍ່ມີ login ແຕ່ມີ `ANTHROPIC_API_KEY` ໃນ `.env` (ທາງເລືອກສຳຮອງ) |
| 🔴 ຍັງບໍ່ໄດ້ login Claude Code | ເປີດ Claude Code ໃນ Antigravity ພິມ `/login` ແລ້ວກົດ **ກວດໃໝ່** |

ການກວດ login ບໍ່ໄດ້ສົ່ງຫຍັງໄປຫາໂມເດວ ຈຶ່ງບໍ່ເສຍໂຄຕ້າ.

> ໃຊ້ login ຂອງເຈົ້າເອງໃນເຄື່ອງເຈົ້າເອງໄດ້. **ຫ້າມ**ເອົາແອັບນີ້ໄປໃຫ້ຄົນອື່ນໃຊ້ຜ່ານ login ຂອງເຈົ້າ. ຖ້າຈະແບ່ງປັນ ໃຫ້ໃຊ້ API key. ວຽກຈະນັບເຂົ້າໂຄຕ້າແພັກເກດ Claude ຂອງເຈົ້າ.

## ສັ່ງວຽກ

ກ່ອງລຸ່ມສຸດມີ 3 ແຖວ:

1. **ໂໝດ**
   - 👥 **ໂໝດທີມ**: ສົມພອນ (Tech Lead) ໃຊ້ Superpowers ວາງແຜນ → **ເຈົ້າອະນຸມັດແຜນ** → ລາວແຈກວຽກໃຫ້ພະນັກງານຕາມບົດບາດ (ແຕ່ລະຄົນເປັນ sub-agent ທີ່ໃຊ້ໂມເດວຂອງຕົນເອງ) → ແກ້ວ ກວດ, ຕ້ອຍ ເທສ → ສະຫຼຸບເປັນພາສາລາວ
   - 👤 **ຄົນດຽວ**: ມອບວຽກນ້ອຍໃຫ້ຄົນທີ່ເລືອກໂດຍກົງ
2. **ໂປຣເຈັກ ແລະ session**
   - ເລືອກໂຟນເດີໂປຣເຈັກ ຫຼື ກົດ **＋ ໂຟນເດີ** ເພື່ອເລືອກໂຟນເດີໃໝ່
   - **📂 ເປີດໃນ Antigravity**: ເປີດໂຟນເດີນັ້ນໃນ Antigravity ທັນທີ
   - **Session**: ເລືອກ "Session ໃໝ່" ຫຼື **ດຶງ session ເກົ່າ**ຂອງໂຟນເດີນັ້ນມາເຮັດຕໍ່ (ລວມທັງ session ທີ່ເຮັດໃນ Claude Code ຂອງ Antigravity)
3. **ຫົວຂໍ້ ແລະ ລາຍລະອຽດຂອງວຽກ** ແລ້ວກົດ **ສົ່ງວຽກ**

## ລໍຖ້າເຈົ້າ

ກ່ອງ **ລໍຖ້າເຈົ້າ** ຢູ່ແຜງຂວາສະແດງ:
- **ແຜນງານ** (ໂໝດທີມ): ອ່ານແຜນ ແລ້ວກົດ **ອະນຸມັດແຜນ** ຫຼື ຂຽນຄຳແນະນຳແລ້ວກົດ **ໃຫ້ແກ້ແຜນ**. ກ່ອນອະນຸມັດ ບໍ່ມີໃຜແກ້ໄຂໄຟລ໌ໄດ້
- **ຂໍອະນຸຍາດລັນຄຳສັ່ງ**: ອ່ານຄຳສັ່ງໃຫ້ດີ ແລ້ວກົດ ອະນຸຍາດ ຫຼື ບໍ່ອະນຸຍາດ

## ປະຫວັດການສົນທະນາ (ຄືແຊັດຂອງ Claude)

ກົດ **ປະຫວັດການສົນທະນາ** ໃນ sidebar ແລ້ວເລືອກໂປຣເຈັກ ຈະເຫັນທຸກການສົນທະນາຂອງໂຟນເດີນັ້ນ ທັງທີ່ສັ່ງຈາກຫ້ອງການ ແລະ ທີ່ເຮັດໃນ Claude Code ຂອງ Antigravity. ກົດເປີດອັນໃດອັນໜຶ່ງເພື່ອເບິ່ງແບບແຊັດ:
- ຂໍ້ຄວາມຂອງເຈົ້າຢູ່ຂວາ ແລະ ຄຳຕອບຂອງພະນັກງານແຕ່ລະຄົນຢູ່ຊ້າຍ ພ້ອມຮູບ ແລະ ຊື່
- ທຸກ tool (ອ່ານ, ແກ້ໄຂ, ລັນຄຳສັ່ງ, ມອບວຽກ) ເປັນກ່ອງທີ່ກົດເບິ່ງລາຍລະອຽດ ແລະ ຜົນໄດ້
- ການແຈກວຽກ, ແຜນງານ, ການອະນຸມັດ ແລະ ຜົນສຸດທ້າຍ ສະແດງຕາມລຳດັບເວລາ
- ວຽກທີ່ກຳລັງເຮັດອັບເດດສົດ
- **ພິມຕໍ່ໃນກ່ອງລຸ່ມສຸດ** (Enter ເພື່ອສົ່ງ, Shift+Enter ເພື່ອຂຶ້ນແຖວໃໝ່) ເພື່ອເຮັດຕໍ່ໃນ session ດຽວກັນ

ກົດວຽກໃດໜຶ່ງໃນ **ວຽກທັງໝົດ** ກໍຈະເປີດແຊັດຂອງວຽກນັ້ນເຊັ່ນກັນ.

## ເບິ່ງຜົນ ແລະ ເຮັດຕໍ່

ກົດໃສ່ວຽກໃນລາຍການ **ວຽກ** ເພື່ອເບິ່ງແຜນ, ຜົນລັບ, ບັນທຶກວ່າໃຜເຮັດຫຍັງ ແລະ ຄ່າໃຊ້ຈ່າຍໂດຍປະມານ. ມີປຸ່ມ:
- **📂 ເປີດໂຟນເດີ**: ເປີດໂປຣເຈັກໃນ Antigravity ເພື່ອກວດໄຟລ໌ທີ່ປ່ຽນ
- **↩︎ ສືບຕໍ່ session ນີ້**: ສັ່ງວຽກຕໍ່ໃນ session ເດີມ ໂດຍທີມຍັງຈື່ສິ່ງທີ່ເຮັດໄປແລ້ວ
- **ຢຸດວຽກນີ້**

## ຂີດຈຳກັດການໃຊ້ງານ (ແຜງຂວາ)

ແຜງຂວາສະແດງ**ຂີດຈຳກັດແທ້**ຂອງແພັກເກດ Claude (ຂໍ້ມູນດຽວກັບຄຳສັ່ງ `/usage` ໃນ Claude Code):
- **ຮອບ 5 ຊົ່ວໂມງ**: ໃຊ້ໄປຈັກ % ແລະ ຣີເຊັດໃນອີກຈັກຊົ່ວໂມງ
- **ລາຍອາທິດ**: ໃຊ້ໄປຈັກ % ແລະ ຣີເຊັດມື້ໃດ (ແລະ ແຍກຕາມໂມເດວ ຖ້າແພັກເກດມີ)

ອັບເດດທຸກ 1 ນາທີ, ຫຼັງວຽກແຕ່ລະອັນແລ້ວ ແລະ ເມື່ອກົດ **ອັບເດດ**. ຖ້າຮອບ 5 ຊົ່ວໂມງເຕັມ ຈະບໍ່ຮັບວຽກໃໝ່ຈົນກວ່າຈະຣີເຊັດ. ຖ້າໃຊ້ API key ຈະບໍ່ມີຂີດຈຳກັດນີ້.

> SDK ໝາຍການອ່ານຂໍ້ມູນນີ້ວ່າ "ກຳລັງທົດລອງ" ຈຶ່ງອາດປ່ຽນໄປໃນ SDK ລຸ້ນໃໝ່.

## ປ່ຽນໂມເດວ

ກົດໃສ່ພະນັກງານ ແລ້ວເລືອກ **ໂມເດວ** (Haiku / Sonnet / Opus / Fable) ແລະ **ລະດັບການຄິດ**. ການຕັ້ງຄ່ານີ້ໃຊ້ທັງຕອນເຮັດວຽກຄົນດຽວ ແລະ ຕອນເປັນ sub-agent ໃນໂໝດທີມ. ບັນທຶກລົງ `config/team.json` ທັນທີ.

## ສິດຂອງແຕ່ລະຄົນ

- **ອ່ານໄດ້ຢ່າງດຽວ** (CEO, Code Reviewer, Security Engineer, Scrum Master): ອ່ານ ແລະ ຄົ້ນຫາເທົ່ານັ້ນ ບໍ່ສາມາດລັນຄຳສັ່ງ ຫຼື ແກ້ໄຂໄຟລ໌
- **ອ່ານ ແລະ ແກ້ໄຂໄດ້** (ຄົນອື່ນ): ແກ້ໄຂໄຟລ໌ໃນໂປຣເຈັກໄດ້ເອງ ແຕ່ **ການລັນຄຳສັ່ງ ແລະ ການເຂົ້າເຖິງນອກໂປຣເຈັກຕ້ອງຂໍອະນຸຍາດ**
- ທຸກຄົນຖືກສັ່ງວ່າຫ້າມ push, deploy ຫຼື publish

## ການຕັ້ງຄ່າ (`.env`, ບໍ່ບັງຄັບ)

ສຳເນົາ `.env.example` ເປັນ `.env` ຖ້າຢາກປ່ຽນຄ່າ:

| ຕົວແປ | ຄວາມໝາຍ | ຄ່າເລີ່ມຕົ້ນ |
|---|---|---|
| `ANTHROPIC_API_KEY` | ໃຊ້ສະເພາະຕອນບໍ່ໄດ້ login Claude Code | (ບໍ່ມີ) |
| `PORT` | port ຂອງໜ້າເວັບ | 4317 |
| `WORKSPACE_DIR` | ໂຟນເດີໂປຣເຈັກເລີ່ມຕົ້ນ | `./workspace` |
| `TEAM_LEAD` | ຫົວໜ້າທີ່ວາງແຜນ ແລະ ແຈກວຽກ | `somphone` |
| `TASK_BUDGET_USD` / `TEAM_BUDGET_USD` | ເພດານຄ່າໃຊ້ຈ່າຍໂດຍປະມານຕໍ່ວຽກ (ຄົນດຽວ / ທີມ) | 1.00 / 5.00 |

## ໂຄງສ້າງໂປຣເຈັກ

```
ai-office/
├── server/
│   ├── index.js     # web server, ຄິວວຽກ, ການອະນຸມັດ, ອັບເດດສົດ (SSE)
│   ├── runner.js    # ໂໝດຄົນດຽວ ແລະ ໂໝດທີມ (Tech Lead + sub-agent + Superpowers)
│   ├── auth.js      # ກວດ login Claude Code / API key ໂດຍບໍ່ເສຍໂຄຕ້າ
│   ├── projects.js  # ລາຍການໂປຣເຈັກ, ເປີດໃນ Antigravity, ດຶງ session ເກົ່າ
│   └── store.js     # ບັນທຶກວຽກລົງ data/state.json
├── web/             # ໜ້າຫ້ອງການ 2D (ຮູບຈາກ vao/model, vao/room, vao/item)
├── config/team.json # ບົດບາດ, prompt, ໂມເດວ ແລະ ສິດຂອງແຕ່ລະຄົນ
└── workspace/       # ໂຟນເດີໂປຣເຈັກເລີ່ມຕົ້ນ
```

## ຂໍ້ຄວນຮູ້

- ໂໝດທີມຈະໃຊ້ Superpowers ຖ້າຕິດຕັ້ງໄວ້ໃນ Claude Code ຂອງເຈົ້າ. ຖ້າບໍ່ມີ ສົມພອນຈະວາງແຜນເອງ
- ໃນໂໝດທີມ ຄົນທີ່ອ່ານຢ່າງດຽວເຮັດວຽກພ້ອມກັນໄດ້ ສ່ວນຄົນທີ່ແກ້ໄຟລ໌ເຮັດເທື່ອລະຄົນ
- ຄົນດຽວຮັບໄດ້ເທື່ອລະວຽກ ວຽກອື່ນຈະເຂົ້າຄິວ
- ຄ່າໃຊ້ຈ່າຍເປັນການຄາດຄະເນຈາກ SDK. ວຽກທີ່ຖືກຢຸດກາງຄັນຈະບໍ່ຖືກນັບ
- server ເປີດສະເພາະໃນເຄື່ອງນີ້ (`127.0.0.1`)
