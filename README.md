# ຫ້ອງການ AI Dev

ຫ້ອງການ 2D ທີ່ພະນັກງານ AI ທັງ 15 ຄົນ**ເຮັດວຽກແທ້**ດ້ວຍ [Claude Agent SDK](https://code.claude.com/docs/en/agent-sdk). ເຈົ້າສັ່ງວຽກ ແລ້ວເບິ່ງພວກເຂົາປະຊຸມວາງແຜນ, ຍ່າງກັບໂຕະ, ອ່ານ ແລະ ແກ້ໄຂໄຟລ໌ ແລະ ຂໍອະນຸຍາດກ່ອນລັນຄຳສັ່ງ.

## ເປີດໃຊ້

ຕ້ອງມີ Node.js 18 ຂຶ້ນໄປ ແລະ **login Claude Code ໄວ້ໃນເຄື່ອງນີ້** (ເຊັ່ນ ຜ່ານ extension Claude Code ໃນ Antigravity: ພິມ `/login`).

```bash
cd ~/vao/ai-office
npm install
npm start
```

ເປີດ **http://localhost:4317**. ປ້າຍມຸມຊ້າຍເທິງຈະບອກວ່າເຊື່ອມຕໍ່ແລ້ວບໍ:

| ປ້າຍ | ຄວາມໝາຍ |
|---|---|
| 🟢 ເຊື່ອມກັບ Claude Code ແລ້ວ · Claude Pro | ໃຊ້ login Claude Code ຂອງເຈົ້າ (ແບ່ງກັບ Antigravity / CLI) |
| 🟢 ໃຊ້ API key ຈາກ .env | ບໍ່ມີ login ແຕ່ມີ `ANTHROPIC_API_KEY` ໃນ `.env` (ທາງເລືອກສຳຮອງ) |
| 🔴 ຍັງບໍ່ໄດ້ login Claude Code | ເປີດ Claude Code ໃນ Antigravity ພິມ `/login` ແລ້ວກົດ **ກວດໃໝ່** |

ການກວດ login ບໍ່ໄດ້ສົ່ງຫຍັງໄປຫາໂມເດວ ຈຶ່ງບໍ່ເສຍໂຄຕ້າ.

> ໃຊ້ login ຂອງເຈົ້າເອງໃນເຄື່ອງເຈົ້າເອງໄດ້. **ຫ້າມ**ເອົາແອັບນີ້ໄປໃຫ້ຄົນອື່ນໃຊ້ຜ່ານ login ຂອງເຈົ້າ. ຖ້າຈະແບ່ງປັນ ໃຫ້ໃຊ້ API key. ວຽກຈະນັບເຂົ້າໂຄຕ້າແພັກເກດ Claude ຂອງເຈົ້າ.

## ສັ່ງວຽກ

ກ່ອງລຸ່ມສຸດມີ 3 ແຖວ:

1. **ໂໝດ**
   - 👥 **ໂໝດທີມ**: ສົມພອນ (Tech Lead) ໃຊ້ Superpowers ວາງແຜນ → **ເຈົ້າອະນຸມັດແຜນ** → ລາວແຈກວຽກໃຫ້ພະນັກງານຕາມບົດບາດ (ແຕ່ລະຄົນເປັນ sub-agent ທີ່ໃຊ້ໂມເດວຂອງຕົນເອງ) → ແກ້ວ ກວດ, ຕ້ອຍ ເທສ → ສະຫຼຸບເປັນພາສາລາວ
   - 👤 **ຄົນດຽວ**: ມອບວຽກນ້ອຍໃຫ້ຄົນທີ່ເລືອກໂດຍກົງ
2. **ໂປຣເຈັກ ແລະ session**
   - ເລືອກໂຟນເດີໂປຣເຈັກ ຫຼື ກົດ **＋ ໂຟນເດີ** ເພື່ອເລືອກໂຟນເດີໃໝ່
   - **📂 ເປີດໃນ Antigravity**: ເປີດໂຟນເດີນັ້ນໃນ Antigravity ທັນທີ
   - **Session**: ເລືອກ "Session ໃໝ່" ຫຼື **ດຶງ session ເກົ່າ**ຂອງໂຟນເດີນັ້ນມາເຮັດຕໍ່ (ລວມທັງ session ທີ່ເຮັດໃນ Claude Code ຂອງ Antigravity)
3. **ຫົວຂໍ້ ແລະ ລາຍລະອຽດຂອງວຽກ** ແລ້ວກົດ **ສົ່ງວຽກ**
   - ⚡ **ອະນຸຍາດຄຳສັ່ງອັດຕະໂນມັດ**: ເມື່ອຕິກ ຄຳສັ່ງ ແລະ tool ໃນວຽກນັ້ນຈະລັນໂດຍບໍ່ຖາມ. ແຜນໃນໂໝດທີມ ຍັງຕ້ອງອະນຸມັດດ້ວຍມື ແລະ ການອະນຸຍາດອັດຕະໂນມັດຈະເລີ່ມຫຼັງແຜນຖືກອະນຸມັດ. ບຣາວເຊີຈື່ການເລືອກນີ້ໄວ້

## ລໍຖ້າເຈົ້າ

ກ່ອງ **ລໍຖ້າເຈົ້າ** ຢູ່ແຜງຂວາສະແດງ:
- **ແຜນງານ** (ໂໝດທີມ): ອ່ານແຜນ ແລ້ວກົດ **ອະນຸມັດແຜນ** ຫຼື ຂຽນຄຳແນະນຳແລ້ວກົດ **ໃຫ້ແກ້ແຜນ**. ກ່ອນອະນຸມັດ ບໍ່ມີໃຜແກ້ໄຂໄຟລ໌ໄດ້
- **ຂໍອະນຸຍາດລັນຄຳສັ່ງ**: ອ່ານຄຳສັ່ງໃຫ້ດີ ແລ້ວກົດ ອະນຸຍາດ ຫຼື ບໍ່ອະນຸຍາດ
- ⚡ **ອະນຸຍາດອັດຕະໂນມັດ**: ເປັນແຖບຢູ່ເທິງສຸດຂອງແຜງ ສະແດງຕະຫຼອດ. ມີສະວິດຂອງແຕ່ລະວຽກທີ່ຢູ່ໃນຄິວ ຫຼື ກຳລັງເຮັດ ແລະ ສະວິດສະແດງສະຖານະດັ່ງນີ້:
  - **ເປີດ**
  - **ປິດ**
  - **ລໍຖ້າອະນຸມັດແຜນ**: ໂໝດທີມ ກ່ອນແຜນຖືກອະນຸມັດ
  - ກົດສະວິດເພື່ອເປີດ ຫຼື ປິດ. ສະວິດດຽວກັນຍັງສະແດງໃນແຊັດຂອງວຽກນັ້ນ ແລະ ວຽກທີ່ເປີດຢູ່ຈະມີ ⚡ ໃນລາຍການວຽກ
  - ປຸ່ມ **ອະນຸຍາດທັງໝົດໃນວຽກນີ້** ໃນກ່ອງຂໍອະນຸຍາດລັນຄຳສັ່ງຍັງໃຊ້ໄດ້ ແລະ ຈະເປີດສະວິດນີ້
  - ໃຊ້ສະເພາະວຽກນັ້ນ ເມື່ອວຽກຈົບ ຫຼື ຖືກຢຸດ ສະວິດຈະປິດເອງ. ທຸກການກະທຳທີ່ອະນຸຍາດອັດຕະໂນມັດຖືກບັນທຶກໃນແຊັດດ້ວຍ ⚡. ໃຊ້ສະເພາະວຽກທີ່ເຈົ້າໄວ້ໃຈ

## ປະຫວັດການສົນທະນາ (ຄືແຊັດຂອງ Claude)

ກົດ **ປະຫວັດການສົນທະນາ** ໃນ sidebar ແລ້ວເລືອກໂປຣເຈັກ ຈະເຫັນທຸກການສົນທະນາຂອງໂຟນເດີນັ້ນ ທັງທີ່ສັ່ງຈາກຫ້ອງການ ແລະ ທີ່ເຮັດໃນ Claude Code ຂອງ Antigravity. ກົດເປີດອັນໃດອັນໜຶ່ງເພື່ອເບິ່ງແບບແຊັດ:
- ຂໍ້ຄວາມຂອງເຈົ້າຢູ່ຂວາ ແລະ ຄຳຕອບຂອງພະນັກງານແຕ່ລະຄົນຢູ່ຊ້າຍ ພ້ອມຮູບ ແລະ ຊື່
- ທຸກ tool (ອ່ານ, ແກ້ໄຂ, ລັນຄຳສັ່ງ, ມອບວຽກ) ເປັນກ່ອງທີ່ກົດເບິ່ງລາຍລະອຽດ ແລະ ຜົນໄດ້
- ການແຈກວຽກ, ແຜນງານ, ການອະນຸມັດ ແລະ ຜົນສຸດທ້າຍ ສະແດງຕາມລຳດັບເວລາ
- ວຽກທີ່ກຳລັງເຮັດອັບເດດສົດ
- **ພິມຕໍ່ໃນກ່ອງລຸ່ມສຸດ** (Enter ເພື່ອສົ່ງ, Shift+Enter ເພື່ອຂຶ້ນແຖວໃໝ່) ເພື່ອເຮັດຕໍ່ໃນ session ດຽວກັນ

ກົດວຽກໃດໜຶ່ງໃນ **ວຽກທັງໝົດ** ກໍຈະເປີດແຊັດຂອງວຽກນັ້ນເຊັ່ນກັນ.

## ເບິ່ງຜົນ ແລະ ເຮັດຕໍ່

ກົດໃສ່ວຽກໃນລາຍການ **ວຽກ** ເພື່ອເບິ່ງແຜນ, ຜົນລັບ, ບັນທຶກວ່າໃຜເຮັດຫຍັງ ແລະ ຄ່າໃຊ້ຈ່າຍໂດຍປະມານ. ມີປຸ່ມ:
- **📂 ເປີດໂຟນເດີ**: ເປີດໂປຣເຈັກໃນ Antigravity ເພື່ອກວດໄຟລ໌ທີ່ປ່ຽນ
- **↩︎ ສືບຕໍ່ session ນີ້**: ສັ່ງວຽກຕໍ່ໃນ session ເດີມ ໂດຍທີມຍັງຈື່ສິ່ງທີ່ເຮັດໄປແລ້ວ
- **ຢຸດວຽກນີ້**

## ຂີດຈຳກັດການໃຊ້ງານ (ແຜງຂວາ)

ແຜງຂວາສະແດງ**ຂີດຈຳກັດແທ້**ຂອງແພັກເກດ Claude (ຂໍ້ມູນດຽວກັບຄຳສັ່ງ `/usage` ໃນ Claude Code):
- **ຮອບ 5 ຊົ່ວໂມງ**: ໃຊ້ໄປຈັກ % ແລະ ຣີເຊັດໃນອີກຈັກຊົ່ວໂມງ
- **ລາຍອາທິດ**: ໃຊ້ໄປຈັກ % ແລະ ຣີເຊັດມື້ໃດ (ແລະ ແຍກຕາມໂມເດວ ຖ້າແພັກເກດມີ)

ອັບເດດທຸກ 1 ນາທີ, ຫຼັງວຽກແຕ່ລະອັນແລ້ວ ແລະ ເມື່ອກົດ **ອັບເດດ**. ຖ້າຮອບ 5 ຊົ່ວໂມງເຕັມ ຈະບໍ່ຮັບວຽກໃໝ່ຈົນກວ່າຈະຣີເຊັດ. ຖ້າໃຊ້ API key ຈະບໍ່ມີຂີດຈຳກັດນີ້.

> SDK ໝາຍການອ່ານຂໍ້ມູນນີ້ວ່າ "ກຳລັງທົດລອງ" ຈຶ່ງອາດປ່ຽນໄປໃນ SDK ລຸ້ນໃໝ່.

## ການປະຢັດ token

ໂໝດທີມຖືກອອກແບບໃຫ້ກິນໂຄຕ້າໜ້ອຍ:
- **ດຳເນີນຕໍ່ session ໃຫຍ່**: ຖ້າ session ເກົ່າໃຫຍ່ກວ່າ `RESUME_MAX_TOKENS` ຈະເລີ່ມ session ໃໝ່ ໂດຍເອົາໄປແຕ່ສະຫຼຸບ (ເປົ້າໝາຍ, ແຜນລ່າສຸດ, ຄຳຕອບລ່າສຸດ). ລາຍການ session ສະແດງຂະໜາດ (~k token) ແລະ ⚠️ ສຳລັບອັນທີ່ໃຫຍ່
- **ສອງຊ່ວງ**: ສົມພອນ ວາງແຜນດ້ວຍ Superpowers `writing-plans` (ບໍ່ໃຊ້ brainstorming) → ເຈົ້າອະນຸມັດ → session **ໃໝ່** ທີ່ເອົາໄປແຕ່ແຜນ ແລ້ວແຈກວຽກດ້ວຍ `subagent-driven-development`. ສິ່ງທີ່ອ່ານຕອນວາງແຜນບໍ່ຕິດໄປນຳ
- **ສຸກ (Code Scout, Haiku)** ສຳຫຼວດໂຄດແທນຫົວໜ້າ ແລະ ສົ່ງສະຫຼຸບສັ້ນໆ. ຫົວໜ້າອ່ານໄຟລ໌ໄດ້ເທື່ອລະບໍ່ເກີນ 300 ແຖວ ແລະ ລັນໄດ້ແຕ່ git ແບບອ່ານ ກັບ script ຂອງ Superpowers
- **ກວດຄັ້ງດຽວ**: ແກ້ວ ກວດ ແລະ ຕ້ອຍ ເທສ ເທື່ອດຽວຫຼັງວຽກທັງໝົດແລ້ວ, ແກ້ຄືນໄດ້ 1 ຮອບ. ສີ, CEO, ທອງ ຈະຖືກເອີ້ນສະເພາະເມື່ອແຜນລະບຸ
- ພະນັກງານລາຍງານກັບຫົວໜ້າສັ້ນໆ (ບໍ່ເກີນ 200–250 ຄຳ)

## ປ່ຽນໂມເດວ

ກົດໃສ່ພະນັກງານ ແລ້ວເລືອກ **ໂມເດວ** (Haiku / Sonnet / Opus / Fable) ແລະ **ລະດັບການຄິດ**. ການຕັ້ງຄ່ານີ້ໃຊ້ທັງຕອນເຮັດວຽກຄົນດຽວ ແລະ ຕອນເປັນ sub-agent ໃນໂໝດທີມ. ບັນທຶກລົງ `config/team.json` ທັນທີ.

### ໜ້າກາກເສື້ອ (ສຳລັບການປ່ຽນສີເສື້ອ)

ແຕ່ລະຮູບຕົວລະຄອນມີ **ໜ້າກາກເສື້ອ** ຢູ່ `web/assets/shirts/<ຮູບ>.png` ບອກວ່າ pixel ໃດແມ່ນເສື້ອ. ການປ່ຽນສີຈະທາສີສະເພາະບ່ອນນັ້ນ. ໜ້າກາກຂອງທັງ 15 ຮູບຖືກສ້າງ ແລະ ກວດແກ້ແລ້ວ.

ຖ້າເຫັນຈຸດທີ່ປ່ຽນສີຜິດ ຫຼື ບໍ່ປ່ຽນ ໃຫ້ເປີດ **http://localhost:4317/mask-editor.html**:
- ເລືອກຮູບ ແລະ ສີທົດລອງ, ກົດເຟຣມທີ່ຢາກແກ້
- 🖌 **ເພີ່ມ** ແຕ້ມເທິງສ່ວນທີ່ເປັນເສື້ອ, 🧽 **ລຶບ** ສ່ວນທີ່ບໍ່ແມ່ນເສື້ອ (ກົດ Shift ຄ້າງ = ລຶບຊົ່ວຄາວ), **↶ ຍ້ອນກັບ** ໄດ້
- **↻ ເຟຣມນີ້ອັດຕະໂນມັດ** ສ້າງເຟຣມນັ້ນໃໝ່

ຮູບໃໝ່ທີ່ຍັງບໍ່ມີໜ້າກາກ ຈະໃຊ້ການຊອກຫາເສື້ອອັດຕະໂນມັດແທນ.

## ໂໝດມືດ / ສະຫວ່າງ

ໃນແຖບຊ້າຍ ກຸ່ມ **ມຸມມອງ** ມີປຸ່ມ **ໂໝດສີ**. ກົດແຕ່ລະຄັ້ງຈະວົນໄປດັ່ງນີ້:
- **ອັດຕະໂນມັດ**: ຕາມການຕັ້ງຄ່າ OS ຂອງເຄື່ອງ
- **ສະຫວ່າງ**, ຈາກນັ້ນ **ມືດ**, ແລ້ວກັບມາ **ອັດຕະໂນມັດ**

ການເລືອກຈະຖືກຈື່ໄວ້ໃນບຣາວເຊີນີ້ (localStorage) ຈຶ່ງຍັງຢູ່ຫຼັງ reload. ໃນໂໝດອັດຕະໂນມັດ ຖ້າ theme ຂອງ OS ປ່ຽນ ໜ້າຈໍຈະປ່ຽນຕາມທັນທີ.

### ຂະໜາດຕົວໜັງສື ແລະ ສີ

ໃນ **⚙️ ການຕັ້ງຄ່າ → ໜ້າຕາ: ຂະໜາດຕົວໜັງສື ແລະ ສີ**:
- **ຂະໜາດຕົວໜັງສື**: 80% ຫາ 150% (ເລື່ອນ ຫຼື ກົດ A− / A+). ໃຊ້ກັບທຸກໜ້າຂອງລະບົບ
- **ສີຫຼັກ** (ປຸ່ມ, ລິ້ງ, ສະວິດ) ແລະ **ສີພື້ນຫຼັງ**: ປັບດ້ວຍແຖບ **R G B** (0–255), ພິມຕົວເລກ, ເລືອກຈາກຕົວເລືອກສີ ຫຼື ກົດສີສຳເລັດຮູບ. ສີອ່ອນ/ເຂັ້ມຂອງສີຫຼັກຖືກຄິດໃຫ້ເອງ ແລະ ສີຕົວໜັງສືເທິງປຸ່ມປ່ຽນເປັນດຳ/ຂາວໃຫ້ອ່ານງ່າຍ
- ສີແຍກກັນລະຫວ່າງ **ໂໝດສະຫວ່າງ** ແລະ **ໂໝດມືດ**: ຕັ້ງສີຂອງໂໝດທີ່ເຫັນຢູ່. **ໃຊ້ສີເດີມ** ຄືນສີນັ້ນ, **ຄືນຄ່າເລີ່ມຕົ້ນ** ຄືນທັງໝົດ
- ຈື່ໄວ້ໃນບຣາວເຊີນີ້ຄືກັບໂໝດສີ

ລັນ test ຂອງສ່ວນນີ້ດ້ວຍ `npm test`

## ການຕັ້ງຄ່າ (⚙️ ໃນແຖບຂ້າງ)

ກົດ **⚙️ ການຕັ້ງຄ່າ** ໃນແຖບຂ້າງຊ້າຍ. ບັນທຶກອັດຕະໂນມັດລົງ `data/settings.json` ແລະ ມີຜົນກັບວຽກຕໍ່ໄປທັນທີ (ບໍ່ຕ້ອງ restart). ແຕ່ລະໝວດມີປຸ່ມ **ຄືນຄ່າເລີ່ມຕົ້ນ**:
- ໝວດ **ການໃຊ້ token ແລະ ງົບປະມານ** ແລະ **ທີມ ແລະ ຂັ້ນຕອນ** ມີ **ສະວິດເປີດ/ປິດ** ຢູ່ເທິງສຸດ. ເມື່ອປິດ ລະບົບໃຊ້ຄ່າເລີ່ມຕົ້ນຂອງໝວດນັ້ນທັງໝົດ (ເຊັ່ນ ເພດານ 1.00 / 1.50 USD, ຢຸດທີ່ 90%, ຫົວໜ້າເລີ່ມຕົ້ນ, ພະນັກງານທຸກຄົນເຮັດວຽກ) ແຕ່ຄ່າທີ່ເຈົ້າຕັ້ງໄວ້ຍັງເກັບໄວ້ ແລະ ກັບມາໃຊ້ເມື່ອເປີດຄືນ
- **ການໃຊ້ token ແລະ ງົບປະມານ**: ເພດານຄ່າໃຊ້ຈ່າຍຕໍ່ວຽກ, ຂະໜາດ session ທີ່ "ດຳເນີນຕໍ່" ໄດ້, ຢຸດຮັບວຽກເມື່ອຮອບ 5 ຊົ່ວໂມງຮອດ X% (ເລີ່ມຕົ້ນ 90%), ເຕືອນໂຄຕ້າລາຍອາທິດ, ເຕືອນຄຳຂໍທີ່ລໍຖ້າດົນ, ຈຳນວນແຖວທີ່ຫົວໜ້າອ່ານໄດ້
- **ທີມ ແລະ ຂັ້ນຕອນ**: ຫົວໜ້າທີມ, ເປີດ/ປິດພະນັກງານ ແລະ ຈຳນວນຮອບ (maxTurns) ຂອງແຕ່ລະຄົນ, Superpowers, ແຍກຊ່ວງວາງແຜນ/ລົງມືເຮັດ, TDD, ໃຫ້ QA ເທສທຸກວຽກ, ໃຫ້ກວດຄວາມປອດໄພທຸກວຽກ, ຈຳນວນຮອບແກ້ຄືນ
- **ຄວາມປອດໄພ**: ເປີດອະນຸຍາດອັດຕະໂນມັດໃຫ້ວຽກໃໝ່, **ຄຳສັ່ງທີ່ອະນຸຍາດອັດຕະໂນມັດ** (ຕ້ອງຂຶ້ນຕົ້ນດ້ວຍຄຳສັ່ງໃນລາຍການ ແລະ ບໍ່ມີ `; & | > \` $`) ແລະ **ຄຳສັ່ງທີ່ປະຕິເສດສະເໝີ** (ເຊັ່ນ `git push`, `rm -rf`). ລາຍການຫ້າມຊະນະສະເໝີ, ແມ່ນແຕ່ຕອນເປີດອະນຸຍາດອັດຕະໂນມັດ
- **ການແຈ້ງເຕືອນ**: ແຈ້ງເຕືອນຂອງ browser ແລະ ສຽງ ເມື່ອມີແຜນລໍຖ້າ, ມີຄຳຂໍອະນຸຍາດ, ຫຼື ວຽກຈົບ. ແຈ້ງເຕືອນຂອງລະບົບຈະຂຶ້ນສະເພາະຕອນບໍ່ໄດ້ເບິ່ງໜ້ານີ້ຢູ່

- **ໂປຣເຈັກ ແລະ ເຄື່ອງມື**: ໂຟນເດີເລີ່ມຕົ້ນ, ເປີດໂຟນເດີດ້ວຍ Antigravity / VS Code / Finder, ຄວາມເລິກ ແລະ ໂຟນເດີທີ່ຂ້າມເວລາຄົ້ນຫາ
- **ພາສາ ແລະ ການລາຍງານ**: ພາສາບົດສະຫຼຸບ (ລາວ / English / ไทย), ສັ້ນ ຫຼື ລະອຽດ, ແລະ ຄວາມຍາວລາຍງານຂອງພະນັກງານຫາຫົວໜ້າ
- **ການສະແດງຜົນ**: ຄວາມໄວການເຄື່ອນໄຫວ ແລະ ເປີດ/ປິດຂໍ້ຄວາມເທິງຫົວພະນັກງານ
- **ຂໍ້ມູນ ແລະ ປະຫວັດ**: ຈຳນວນວຽກ ແລະ ຂໍ້ຄວາມທີ່ເກັບໄວ້, **Export ປະຫວັດ (JSON)**, **ລ້າງວຽກທີ່ຈົບແລ້ວ** (ວຽກທີ່ກຳລັງເຮັດຢູ່ບໍ່ຖືກລຶບ)

`ANTHROPIC_API_KEY` ແລະ `PORT` ຕັ້ງໄດ້ໃນ `.env` ເທົ່ານັ້ນ.

## ຄ່າເລີ່ມຕົ້ນຈາກ `.env` (ບໍ່ບັງຄັບ)

ສຳເນົາ `.env.example` ເປັນ `.env` ຖ້າຢາກປ່ຽນຄ່າ:

| ຕົວແປ | ຄວາມໝາຍ | ຄ່າເລີ່ມຕົ້ນ |
|---|---|---|
| `ANTHROPIC_API_KEY` | ໃຊ້ສະເພາະຕອນບໍ່ໄດ້ login Claude Code | (ບໍ່ມີ) |
| `PORT` | port ຂອງໜ້າເວັບ | 4317 |
| `WORKSPACE_DIR` | ໂຟນເດີໂປຣເຈັກເລີ່ມຕົ້ນ | `./workspace` |
| `TEAM_LEAD` | ຫົວໜ້າທີ່ວາງແຜນ ແລະ ແຈກວຽກ | `somphone` |
| `TASK_BUDGET_USD` / `TEAM_BUDGET_USD` | ເພດານຄ່າໃຊ້ຈ່າຍໂດຍປະມານຕໍ່ວຽກ (ຄົນດຽວ / ທີມ) | 1.00 / 1.50 |
| `RESUME_MAX_TOKENS` | session ທີ່ໃຫຍ່ກວ່ານີ້ ເວລາກົດ "ດຳເນີນຕໍ່" ຈະເລີ່ມ session ໃໝ່ພ້ອມສະຫຼຸບແທນ | 50000 |
